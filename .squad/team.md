## Project Context

- **Project:** scoundrel
- **Created:** 2026-11-20
- **Owner:** Jonny Bowen
- **Description:** Scoundrel — lightweight, web-based single-player dungeon card game (Zach Gage & Kurt Bieg rules) with a Balatro-like look: crunchy pixel graphics, CRT shader, juicy animation, and sound.
- **Universe:** Battlestar Galactica
- **Assumptions (defaults, change any time):** TypeScript + Vite; Canvas/WebGL rendering with a CRT post-process; Web Audio API for SFX/music; Vitest (rules) + Playwright (e2e); static site, no backend; desktop and mobile browsers.
