# Project Context

- **Owner:** Jonny Bowen
- **Project:** Scoundrel - a lightweight, web-based single-player dungeon card game (rules by Zach Gage & Kurt Bieg), styled after Balatro with crunchy pixel graphics, juicy animation, and sound.
- **Stack (assumed default):** TypeScript + Vite, HTML Canvas/WebGL with a CRT post-process shader, Web Audio API, Vitest + Playwright. Static site, no backend.
- **Created:** 2026-11-20

## Learnings

- 2026-11-20: Built FxDirector (src/fx/director.ts, easing.ts) and AudioEngine (src/audio/engine.ts, synth.ts, music.ts). The FX model is event -> Step {duration, cueAt, gap}. Cards referenced by queued steps are locked: FX owns their pose, and an undealt card stays hidden at the deck. Ownership passes to the newest step, cues fire strictly in event order, and a milestone loop keeps large dt deterministic. skip/reduced motion = flush in order.
- Engine semantics: the killing blow is MonsterFought -> DamageTaken -> GameLost with no MonsterSlain, and the monster becomes a ghost that fades. RoomCleared(carried null) comes before GameWon. An implicit entry emits RoomEntered first. A potion at full HP is PotionWasted. createSession does not broadcast opening events; the app must subscribe then newGame. Session.replay emits one huge batch, so the UI should call fx.skip() after replay/load.
- Audio: everything is synthesized (no assets). The context is created only in unlock(). Per-id retrigger coalescing is 30ms with a cap of 16 voices. Music is a look-ahead 16th-note sequencer with seeded A A B B phrases. Win/lose jingles are followed by delayed title/gameOver music.
- 2026-11-20: Revised Tigh's rules suite after Adama's REJECT (I was the lockout successor). Death on a room-completing card must emit exactly MonsterFought, DamageTaken, GameLost. No MonsterSlain, RoomCleared, CardDealt or RoomRevealed. The leftover stays in its slot, the deck is untouched, the killer is discarded, and weapon.slain is unchanged. The tests are in scoring.test.ts ("death on the card that would complete a non-final room"), and fuzz playOut checks every losing batch. Mutation proof: a scratch engine copy that pushes RoomCleared before GameLost fails 9 tests. To run a mutant, copy src/game and tests/unit into the scratchpad, junction node_modules in, and run vitest there; src stays untouched. Fuzz its now carry FUZZ_TIMEOUT_MS = 30_000, and the search tier uses 100 seeds (about 0.5s each); fuzz.test.ts takes about 2.6s in total. Per-file timing comes from `vitest run --reporter=json --outputFile=...`. For FX this confirms that a death batch never contains RoomCleared, so the director must not wait for a clear on loss.
- 2026-11-20 (DR2 tutorial FX/audio): src/fx/coach.ts CoachFxTrack. Every value is a closed-form function of the time since its cue, so one big dt matches many small ones and runs are deterministic. pulse = 0.5+0.5cos (it restarts bright on coachShown, period 1400). bob = 3*sin^2 (period 760). bump, shake and success are eased decays (200/280/480 ms; completed gives a 320 bump and a 1100 success). COACH_TIMING and COACH_STATIC are exported. Under reduced motion the track returns COACH_STATIC (pulse 0.5) and ignores cues. Director hook: one track, update(dt) inside update(), setReducedMotion forwarded, tutorialCue() never touches the queue or cues. FxFrame.coach is present only after the first tutorialCue, so normal-play frames are byte-identical; render must gate the overlay on chrome.tutorial, not on frame.coach. skip() does not cancel coach animation. Audio: TutorialSfxId is merged into SfxId (`TutorialSfxId | ...`). The voices: coachBlip is sine A5->E6 with peak 0.06, under uiClick; nudges use pitch 0.8. stepSuccess is a G5-D6-G6 triangle chime (0.36s). tutorialComplete is a fanfare ending on a G chord (0.9s, shorter than win). Tests: src/fx/coach.test.ts and src/fx/director.coach.test.ts (busy/cue/card traces are identical with tutorial cues spammed), and src/audio/synth.test.ts, which uses a recording fake BaseAudioContext and is reusable for voice-shape checks. When a teammate's in-progress file breaks `npm run build`, verify your own part with filtered tsc and `vite build --outDir <scratchpad>`.
- 2026-11-20 (DR2 tutorial-machine, lockout successor for Tyrol): fixed Adama's R1 in src/tutorial/machine.ts advance('events'). The order is now GameLost -> desynced, then GameWon -> recap (last stepIndex, page 0, nudge cleared, whether or not the trigger hit), then trigger match -> complete + checkSync. Updated the header advance rules to match.
